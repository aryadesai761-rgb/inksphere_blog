# INKSPHERE — Ideas Beyond Words

A responsive editorial-style blogging website made with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and sample stories
- `style.css` — responsive layout, colors, and visual design
- `script.js` — search, category filters, like buttons, theme switch, mobile menu, and demo newsletter form

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository, e.g. `inksphere-blog`.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for deployment and open the published URL shown in the Pages section.

The newsletter is a front-end demo only; it does not store email addresses. Replace the sample author names and stories with your friend's details/content before submitting.
